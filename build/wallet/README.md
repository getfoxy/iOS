# build/wallet — the wallet, by part

The wallet (all money logic) is kept here in parts by feature, so it can be read a part at a time. `tools/join-sources.py` joins these files, in name order, into `Web/foxy-wallet.js` — the file that is used — and `sh tools/check-all.sh` fails if the two ever differ. **Edit these files, never `Web/foxy-wallet.js`,** then run `python3 tools/pack-index.py`.

The parts are pieces of one file, not separate modules: they share one scope, so a part is not valid JavaScript on its own. This table is regenerated on every join.
