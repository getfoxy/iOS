# build/app — the app class, by part

The app component (every screen's behaviour) is kept here in parts by feature, so it can be read a part at a time. `tools/join-sources.py` joins these files, in name order, into `build/foxy-app.js` — the file that is used — and `sh tools/check-all.sh` fails if the two ever differ. **Edit these files, never `build/foxy-app.js`,** then run `python3 tools/pack-index.py`.

The parts are pieces of one file, not separate modules: they share one scope, so a part is not valid JavaScript on its own. This table is regenerated on every join.
